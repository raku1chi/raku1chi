# raku1chi

仕事では Python を中心に、主にバックエンドの開発をしています。

個人開発では、公的データやオープンデータ、好きなものを題材に、「調べる・比べる・眺める」が気持ちよくできる Web サービスを作っています。

データを集めるところから、設計・API・画面・公開後の運用まで、一通り手を動かすのが好きです。
